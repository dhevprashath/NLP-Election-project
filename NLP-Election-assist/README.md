# Election Campaign Assistant

A mobile-first Application for Election Campaign queries, built with **Flutter** (Frontend) and **FastAPI** (Backend).

## Project Structure
- `backend/`: FastAPI Python application with NLP logic.
- `frontend/election_assistant_app/`: Flutter mobile application source code.

## 1. Backend Setup (FastAPI)

### Prerequisites
- Python 3.9+

### Installation
1.  Navigate to the `backend` directory:
    ```bash
    cd backend
    ```
2.  Install dependencies:
    ```bash
    pip install -r requirements.txt
    ```

### Running the Server
Run the following command to start the backend server:
```bash
python main.py
```
The server will start at `http://0.0.0.0:8000`.
- API Docs: `http://localhost:8000/docs`

## 2. Frontend Setup (Flutter)

### Prerequisites
- Flutter SDK installed and configured.
- Android Emulator or Real Device connected.

### Installation
Since the Flutter project structure was generated manually, you might need to initialize the platform-specific files if they are missing.

1.  **Create a clean Flutter project** (if you haven't already, or to ensure all platform files exist):
    ```bash
    cd frontend
    flutter create temp_app
    # Move the platform files to our project or copy our lib/pubspec to the temp_app
    # EASIER METHOD:
    # 1. Delete the current 'election_assistant_app' folder (keep a backup of lib/ and pubspec.yaml!)
    # 2. Run: flutter create election_assistant_app
    # 3. Replace 'lib/' and 'pubspec.yaml' with the provided files.
    ```
    *If you simply want to try running the provided code and you already have the platform folders (android/ios) generated by a previous command, skip this step.*

2.  Navigate to the app directory:
    ```bash
    cd frontend/election_assistant_app
    ```

3.  Install dependencies:
    ```bash
    flutter pub get
    ```

### Running the App
1.  Ensure your backend is running (`python main.py`).
2.  Start the Flutter app:
    ```bash
    flutter run
    ```

**Note for Emulator Users**:
The app is configured to use `http://10.0.2.2:8000` to connect to the backend running on your host machine. This is the default alias for Android emulators.

**Note for Real Device Users**:
If running on a physical phone, ensure both phone and PC are on the same Wi-Fi. Update `lib/services/api_service.dart` with your PC's local IP address (e.g., `http://192.168.1.5:8000`).

## 3. Features
- **Slogan Detection**: Identifies party based on slogans.
- **Symbol Identification**: Answers queries about party symbols.
- **Proposed CM**: Returns the CM candidate for a party.
- **Auto-Suggestions**: Suggests party names, leaders, and symbols while typing.
- **Voice Input**: Supports speech-to-text.
- **Domain Restriction**: Politely declines non-election queries.

## 4. API Documentation
- **POST /chat**
    - Body: `{"user_message": "string"}`
    - Response: `{"response_text": "string", "detected_intent": "string", "data": {...}}`
- **GET /suggestions?q=query**
    - Response: `{"suggestions": ["string", ...]}`
